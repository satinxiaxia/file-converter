文件万能转换工具｜独立静态网页

解压后将 index.html 和 assets/ 上传至您有权限的 HTTPS 静态托管平台，保持文件结构。无需内网 App。所有文件仅在浏览器本地处理，不上传。

PDF 页面删除：选择“删除指定页面”，用逗号分隔页码（例如 2,4,5），至少保留一页；导出为新的 PDF。
合并 PDF：多选 PDF、DOCX、PNG、JPG 或 WebP，按文件列表顺序合并为一个 PDF。Word 只提取可选文字、不保留版式；每张图片占一页。
其他限制：PDF→DOCX 仅提取可选文字、扫描件无 OCR；PDF→PPTX 每页一张图片幻灯片（最多20页）；PPTX→PDF 为文字重排版、不保留版式/图片/动画。单次文件总量最多200MB。

部署时务必保留 assets/ 下的 PDF.js Worker 及其他资源。
